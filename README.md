## Introduction
_Artist Showcase Website_ is a project I've made to feature my knowledge of HTML, CSS, JavaScript, web development/design, and front-end skills. I first created this as a Minimal Viable Product (MVP) for my Web Design and Development (CIS*1050) class at the University of Guelph, where I've continued to expand on it since by adding more and more features. This website is dedicated to Dorian Electra, a 2SLGBTQ+ musician mostly specializing in the hyperpop genre.

Access this website at https://artist-showcase-website.vercel.app, hosted on Vercel.

## How I built this project
This project was built with HTML, CSS, and JavaScript. I used several resources to assist me, including GeeksforGeeks, W3Schools, and the course content for Web Design and Development (CIS*1050) @ the University of Guelph.

## What I learned
Although I've used HTML/CSS in the past for either smaller-scale projects or just for fun, this was my first finished, official compilation of HTML/CSS code being used to create a website. This project hence has helped me to become much more comfortable in the fundamentals of HTML/CSS. After building this project with an HTML/CSS foundation, I later added JavaScript to improve the website, also being a new learning experience for myself. Additionally, this is the first project I've hosted on Vercel, which I've appreciated and found to be straight-forward to use.

## What's next for the Artist Showcase Website
I have several features planned to expand this website. This includes:
- More in depth pages to expand on Electra's influence in other areas, coded with HTML/CSS
- JavaScript improvements to tier list page (ex. sorting between a row)
- My personal ranking/leaderboard of Electra's songs, coded with HTML/CSS and JavaScript
